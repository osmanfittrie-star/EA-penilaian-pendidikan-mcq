# HPGD2303 Penilaian Pendidikan — Peperiksaan Mock MCQ

Laman ulang kaji interaktif berdasarkan **BM Modul EA (HPGD2303 Penilaian Pendidikan)**.

## Ciri-ciri

- 5 set peperiksaan mock
- 40 soalan setiap set (200 soalan unik)
- 10 topik, 4 soalan bagi setiap topik dalam setiap set
- Mod Latihan: maklum balas serta-merta dan penerangan
- Mod Peperiksaan: 60 minit dan auto-hantar apabila masa tamat
- Susunan soalan dan pilihan jawapan diacak
- Keputusan, pecahan prestasi mengikut topik dan semakan jawapan
- Sejarah percubaan disimpan pada pelayar
- Tema cerah/gelap, mesra telefon dan boleh dibuka secara offline

## Cara terbitkan di GitHub Pages

1. Cipta repository awam bernama `penilaian-pendidikan-mcq`.
2. Muat naik fail `index.html` dan `README.md` ke bahagian utama repository — **jangan masukkan ke dalam folder**.
3. Tekan **Commit changes**.
4. Buka **Settings > Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**, kemudian tekan **Save**.
7. Pautan akan menjadi:

   `https://osmanfittrie-star.github.io/penilaian-pendidikan-mcq/`
